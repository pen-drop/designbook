# Blueprint: Content Plugin

`plugin.<ns>_content` — the plugin main file. It loads Composer, boots Timber for the theme
(Twig namespace `<ns>` → the theme's `components/`, the same directory Storybook renders),
loads every generated registration file, enqueues the compiled theme stylesheet and announces
the component registry to builder adapters. Plugins load before the theme, so the theme needs
no bootstrap code of its own.

```php
<?php
/**
 * Plugin Name: <Human ns> Content
 * Description: Content model, Timber bootstrap and component registry generated by Designbook.
 */
require_once __DIR__ . '/vendor/autoload.php';
require_once __DIR__ . '/src/ComponentRegistry.php';
require_once __DIR__ . '/src/BricksAdapter.php';
Timber\Timber::init();
add_filter('timber/locations', function ($paths) {
    $paths['<ns>'] = [get_stylesheet_directory() . '/components'];
    $paths[] = [get_stylesheet_directory() . '/views'];
    return $paths;
});
add_filter('timber/twig/environment/options', fn ($o) => ['autoescape' => false] + $o);
add_action('wp_enqueue_scripts', function () {
    $css = get_stylesheet_directory() . '/css/app.css';
    if (is_file($css)) wp_enqueue_style(get_stylesheet(), get_stylesheet_directory_uri() . '/css/app.css', [], (string) filemtime($css));
});
foreach (['post-types', 'taxonomies', 'fields'] as $dir) {
    foreach (glob(__DIR__ . "/$dir/*.php") ?: [] as $file) require_once $file;
}
add_action('designbook/register_components', ['Designbook\\Bricks\\Adapter', 'register']);
add_action('init', function () {
    $registry = new Designbook\ComponentRegistry(get_stylesheet_directory() . '/components', '<ns>');
    do_action('designbook/register_components', $registry);
}, 20);
```

`css/app.css` is the compiled stylesheet (`compile-css`), the same CSS Storybook renders with.

`plugin.<ns>_content.composer` — `composer.json`:

```json
{
  "name": "designbook/<ns>-content",
  "type": "wordpress-plugin",
  "require": { "timber/timber": "^2.3", "symfony/yaml": "^6.4 || ^7.0" }
}
```

`plugin.<ns>_content.registry` — the content of `designbook-wordpress/sync/templates/plugin/src/ComponentRegistry.php`
from the installed skills, copied unchanged.

`plugin.<ns>_content.bricks` — `src/BricksAdapter.php`, copied unchanged.

`plugin.<ns>_content.bricks_elements` — `src/BricksElements.php`, copied unchanged. The Bricks
adapter listens on `designbook/register_components` and no-ops when Bricks is absent.
