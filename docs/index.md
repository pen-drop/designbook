# Manual

Four areas cover first use, extension, integrations, and maintainer work. Open the area that matches what you are doing.

[Get started](/get-started/) is the AI-led path: install skills, initialize a project, run one workflow, inspect Storybook. [Extend Designbook](/extend/) is how configuration and skill contributions change the work. [Integrations](/integrations/) describe Drupal, Tailwind, Stitch, Figma, and GAIA. [Advanced](/advanced/) holds the CLI reference and authoring rules.

Designbook is not a design tool. The landing states the product, inputs, and outputs. There is no Daily work catalog in this handbook.
