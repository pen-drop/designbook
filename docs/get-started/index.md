# Get started

Ask your AI agent to install Designbook, initialize a project, run one small workflow, and inspect the result in Storybook.

This is the AI-led path. You install agent skills, answer project questions, run one workflow, and look at the artifact. You do not orchestrate the whole pipeline by hand for a first result.

1. [What Designbook is](/get-started/what-is-designbook)
2. [Install the skills](/get-started/install)
3. [Initialize a project](/get-started/first-project)
4. [Run one workflow](/get-started/first-workflow)
5. [Skills and workflows](/get-started/skills-and-workflows)
6. [The pipeline](/get-started/pipeline)
7. [Preview in Storybook](/get-started/preview)
8. [Troubleshooting](/get-started/troubleshooting)

Skills are units of work the agent loads. Workflows sequence those skills. The four-level model is introduced here and taught in [Extend Designbook](/extend/).

Designbook is not a design tool. Existing design references are inputs. Storybook is where you inspect the structured output.
